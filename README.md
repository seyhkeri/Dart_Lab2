# Консольное ToDo-приложение на Dart

Консольное приложение для управления списком задач, написанное на языке Dart. Проект разработан в рамках лабораторной работы №2 по изучению основ объектно-ориентированного программирования (ООП).

## Запуск
1. Клонировать репозиторий: `git clone <url>`
2. Перейти в папку: `cd lab2_todo`
3. Установить зависимости: `dart pub get`
4. Запустить: `dart run`

## Ответы на вопросы

### 1. В чём разница между полем класса и обычной переменной в функции?
Поле класса (свойство объекта) принадлежит конкретному экземпляру класса или самому классу, существует в памяти всё время жизни этого объекта и доступно для любых его методов. Обычная переменная в функции является локальной = она создаётся в момент вызова функции и полностью уничтожается после завершения её работы.

### 2. Что такое конструктор и зачем он нужен?
Конструктор - это специальный метод класса, который вызывается автоматически в момент создания нового объекта (экземпляра). Он необходим для инициализации начального состояния объекта, выделения под него памяти и передачи обязательных стартовых данных (например, заголовка задачи).

### 3. Зачем нужен @override перед toString()? Что будет если его убрать?
Аннотация `@override` указывает компилятору, что мы переопределяем стандартный метод `toString()` базового класса `Object` (от которого неявно наследуются все классы в Dart). Она защищает от опечаток в названии метода. Если её убрать, код продолжит работать, но если вы допустите опечатку (например, напишите `tostring()`), компилятор не выдаст ошибку, а создаст новый метод, и стандартный вывод `print(object)` перестанет выдавать кастомную строку.

### 4. Чем статическое поле static int _counter отличается от обычного поля? Сколько копий этого поля существует в программе?
Статическое поле принадлежит самому классу в целом, а не его отдельным объектам. Обычные поля дублируются в памяти для каждого нового экземпляра, в то время как статическое поле всегда существует в системе **строго в одном единственном экземпляре**.

### 5. Что означает нижнее подчёркивание в _counter?
Нижнее подчёркивание перед именем идентификатора (`_`) в языке Dart означает **приватность на уровне файла**. Это делает переменную (или класс/метод) недоступной для использования за пределами того файла, в котором она была объявлена.
